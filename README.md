# Casebook API client

Клиент для взаимодействия с [Casebook API](https://api3.casebook.ru), инкапсулирует авторизацию, механику повторов при ошибках запросов и ограничение количества запросов в минуту.

Автоматизация разработки построена на основе [Task](https://taskfile.dev/), линтинг кода - [golangci-lint](https://golangci-lint.run/).
